# Reusable project blueprint

Copy this scaffold into a new repository. Replace placeholders with project-specific evidence.

## Process
Describe inputs, workflow and outputs.

## Problem
Who experiences the problem? Why does it matter?

## Example
Provide a reproducible example and expected result.

## Impact
Separate demonstrated outcomes from intended benefits.

## Confirm
State acceptance criteria, commands, test results and known limitations.

## Relevant features
Map features to needs and evidence.

## Setup
Document dependencies, installation and execution.

## Attribution
Identify original contributors, upstream sources, license and AI assistance.

## Suggested structure
```
README.md
src/
tests/
examples/
docs/
ROADMAP.md
CHANGELOG.md
AI_USAGE.md
CITATION.cff
```

Select a license only after confirming ownership and third-party obligations. Review secrets, data, assets and history before release.
