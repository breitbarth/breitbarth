# Project standard

Maintainer: Aaron Breitbarth

## Required project explanation
- Process: how the workflow operates.
- Problem: the specific need and affected user.
- Example: a concrete, reproducible scenario.
- Impact: distinguish measured results from intended benefits.
- Confirm: acceptance criteria, tests and limitations.
- Relevant features: connect functionality to the problem.

## Repository conventions
Use README.md, meaningful commit messages, setup and test instructions, and appropriate documentation. Add ROADMAP.md, CHANGELOG.md, AI_USAGE.md and CITATION.cff when warranted. Select licensing deliberately; do not assume public visibility grants reuse rights.

## Release gate
Review source, assets, history, permissions, secrets, personal data, third-party licenses and intellectual property before publication. Label each project as concept, prototype, validated experiment or production system according to evidence.
